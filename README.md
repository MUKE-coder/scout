# Scout

> Point it at your app. See every way in.

Scout is a self-hosted, open-source vulnerability scanner and attack-surface mapper for developers. Give it a URL, a Gin app, a server, or a repo. It probes for weaknesses, merges duplicate findings into one model, scores the result as a letter grade, and ranks the exact fixes by how much safety each one buys per hour of work.

Scout belongs to a family of tools with **Sentinel** (runtime defense) and **Pulse** (observability).

> **Status:** early development. See [`phases.md`](phases.md) for progress.
